# Руководство покупателя

## Главная

`/` — поиск, AI-ассистент, категории, рекомендации, продавцы, товары.

## Светлана

`/svetlana` — главный AI-интерфейс платформы.

Примеры запросов:

- «Найди подарок маме до 10 000 рублей»
- «Найди ноутбук до 100 тысяч для работы и игр»
- «Где мой заказ?»
- «Сравни эти два товара»
- «Найди дешевле»
- «Что говорят об этом товаре?»

Светлана определяет бюджет, назначение, предпочтения, доставку, продавца, отзывы — и формирует **объяснимую** рекомендацию.

## Поиск

| Способ | Где |
|--------|-----|
| Текст | `/catalog` |
| Естественный язык | `/svetlana` |
| По фотографии | через Светлану (photo search) |
| Семантический | гибридный: keyword + vector + фильтры |

Фильтры: категория, цена, продавец, рейтинг, наличие, доставка, атрибуты.

## Карточка товара

`/product/[id]` — фото, описание, характеристики, варианты, цена, наличие, продавец, рейтинг, отзывы, сроки доставки, способы получения, возврат, гарантия, документы, похожие товары, сравнение.

AI-интерфейс прямо в карточке: «Спросить Светлану об этом товаре» — подойдёт ли для задачи, какие аналоги, найди дешевле, сравни, доставят ли завтра.

## Покупка

```
Каталог → Корзина → Чекаут (AI-проверка) → Оплата → Заказ → Отслеживание
```

### Smart cart

Светлана показывает: где цена лучше, можно ли объединить доставку, есть ли дешевле аналог, чего не хватает. **Без навязывания** покупок.

### AI checkout

Перед оплатой Светлана проверяет товары, количество, цену, доставку, адрес, условия продавца, итоговую стоимость — вы получаете понятное резюме.

### Безопасные расчёты

Покупатель платит через платёжного партнёра. Продавец получает деньги **после** выполнения условий сделки. Платформа не хранит ваши деньги.

## Заказы

`/orders` — история. `/orders/[id]` — детали:

- Статус заказа и отгрузки
- Перевозчик, трек-номер
- Предполагаемая доставка
- События доставки
- **Запрос возврата** / **Открыть спор**

## Возвраты и споры (spec §42)

Возврат возможен для доставленных заказов. Спор: товар не получен, не соответствует описанию, повреждение, спор по оплате/доставке.

Светлана собирает доказательства, но **не выносит юридический вердикт** — эскалирует человеку.

## Избранное и wishlist

`/favorites` — избранное и списки желаний. Price alerts — уведомление о снижении цены.

## Рекомендации

`/recommendations` — персональные рекомендации с объяснением «почему рекомендую».

Это отдельный ranking engine, не LLM (spec §28). Учитывает: предпочтения, историю покупок, просмотры, wishlist, контекст, доступность, отзывы.

**Каждая рекомендация объяснима**. Пользователь видит: соответствует бюджету, подходит под задачу, есть доставка, хороший рейтинг.

## Подарки

`/gifts` — AI-помощник подарков: дни рождения, годовщины, праздники.

Учитывает: связь, интересы, wishlist, предыдущие подарки, бюджет, сроки доставки. Исключает уже подаренное.

### Коллективный подарок

Один создаёт, участники приглашаются, каждый **самостоятельно подтверждает участие и свою сумму**. Средства списываются только по явному подтверждению.

## Связи

`/profile/relationships` — семейные, дружеские, рабочие контакты.

Связь не становится фактом по предположению AI. Статусы: `SUGGESTED` → `DECLARED` → `PENDING_CONFIRMATION` → `VERIFIED` / `REJECTED`.

Взаимное подтверждение: вы объявляете связь, второй человек подтверждает — только тогда `VERIFIED`.

## Профиль и конфиденциальность

`/profile` — профиль, интеграции (VK, ЕСИА), настройки AI.

`/privacy` — Privacy Center: что хранится, зачем, откуда, как используется. Кнопки: удалить, экспортировать, отключить, отозвать доступ.

Светлана не собирает данные просто потому, что это технически возможно.
