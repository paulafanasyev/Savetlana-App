# Оплата в АИКО: банки России

Код готов для всех основных способов оплаты в России. Каждый банк включается
переменными окружения на сервере (Vercel → Settings → Environment Variables);
пока переменных нет, работает тестовый режим (sandbox) и живые деньги не ходят.

| Банк / способ | Что покупатель видит | Код | Уведомления (указать в кабинете банка) |
|---|---|---|---|
| ЮKassa | карты, СБП, SberPay, T-Pay, ЮMoney | `domains/yookassa.ts` | `https://<домен>/api/webhooks/yookassa` |
| Т-Банк | карты, СБП (ссылка/QR), T-Pay | `domains/tbank.ts` | передаётся банку автоматически: `/api/webhooks/tbank` |
| Сбербанк | карты, «Мир», SberPay, СБП (страница банка) | `domains/rbs.ts` | передаётся автоматически: `/api/webhooks/sber` |
| Альфа-Банк | карты, «Мир», СБП (страница банка) | `domains/rbs.ts` | передаётся автоматически: `/api/webhooks/alfa` |
| СБП | кнопка «Оплатить через СБП» | ЮKassa и Т-Банк — прямая ссылка СБП; Сбер и Альфа — СБП на странице банка | — |

## Переменные

```
# какой банк основной (если подключено несколько): yookassa | tbank | sber | alfa
PAYMENT_ACQUIRER=tbank

# ЮKassa
YOOKASSA_SHOP_ID=...
YOOKASSA_SECRET_KEY=...
YOOKASSA_RECEIPTS=true          # чек 54-ФЗ от ЮKassa
YOOKASSA_VAT_CODE=1             # 1 = без НДС

# Т-Банк (Т-Бизнес → Интернет-эквайринг → Терминалы)
TBANK_TERMINAL_KEY=...
TBANK_PASSWORD=...
# TBANK_API_URL=https://securepay.tinkoff.ru/v2

# Сбербанк (логин/пароль API-пользователя мерчанта)
SBER_USERNAME=...-api
SBER_PASSWORD=...
# SBER_API_URL=https://securepayments.sberbank.ru/payment/rest   (тест: https://3dsec.sberbank.ru/payment/rest)
SBER_CALLBACK_SECRET=...        # «токен для callback», если банк выдал

# Альфа-Банк
ALFA_USERNAME=...-api
ALFA_PASSWORD=...
# ALFA_API_URL=https://payment.alfabank.ru/payment/rest            (тест: https://alfa.rbsuat.com/payment/rest)
ALFA_CALLBACK_SECRET=...

# Фоновые задачи (сверка оплат, автоотмена) — /api/cron/jobs
CRON_SECRET=...
```

## Как это защищено

- Ключи только на сервере, в браузер не попадают.
- Заказ становится оплаченным только после того, как сервер сам спросил банк
  (GetState / getOrderStatusExtended / API ЮKassa) и банк подтвердил: оплачено,
  сумма совпала с заказом, платёж принадлежит этому заказу.
- Подпись уведомлений проверяется: Т-Банк — Token (SHA-256), Сбер/Альфа — checksum
  (HMAC-SHA256, если задан CALLBACK_SECRET).
- Повтор одного уведомления не применяется дважды.
- **Автовозврат:** если покупатель оплатил дважды (две вкладки) или оплата пришла
  после отмены заказа, лишние деньги сразу возвращаются через тот же банк, покупатель
  получает уведомление. Не вышло — аудит `payment.refund.manual_required`.
- **Сверка:** фоновая задача сама спрашивает банк о платежах без ответа (2 мин — 3 дня).
- **Автоотмена:** заказ без оплаты 24 ч отменяется, товар возвращается в продажу;
  перед отменой сервер спрашивает банк (оплачено — проводим, ждёт — до 72 ч).
- Возврат идёт через тот банк, которым платили.

## Что запросить у банка при подключении

1. Интернет-эквайринг для юрлица/ИП, тип «маркетплейс» (для выплат продавцам —
   сплитование платежей / «Безопасная сделка» / выплаты на карты, отдельный договор).
2. Включить СБП для терминала (Т-Банк, Сбер, Альфа) или в магазине ЮKassa.
3. Онлайн-касса для чеков 54-ФЗ: «Чеки от ЮKassa», «Т-Касса», «Сбер Касса» или АТОЛ Онлайн.
4. Тестовый терминал/стенд — сначала прогоняем тестовую оплату, потом боевой ключ.

## «Оплата по номеру телефона»

Перевод на карту по номеру телефона частного лица для магазина использовать нельзя:
это не эквайринг, нет чека 54-ФЗ, банк заблокирует счёт по 115-ФЗ. Законный
вариант «по телефону» — СБП: покупатель выбирает свой банк и подтверждает оплату
в приложении, деньги приходят на расчётный счёт через эквайера. Это и есть кнопка
«Оплатить через СБП».
