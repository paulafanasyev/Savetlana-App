# Руководство продавца

## Регистрация

1. Создайте аккаунт (`/register`)
2. Создайте профиль продавца — тип: физлицо, самозанятый, ИП или ООО
3. Пройдите верификацию (ИНН, ОГРН/ОГРНИП, статус НПД для самозанятых)
4. Загрузите документы и сертификаты

AI не публикует карточку за вас — публикация юридически значимых данных требует вашего подтверждения (spec §12).

## AI-создание карточки товара (spec §12)

1. Загрузите фотографию товара на `/seller/products`
2. AI подготовит draft: название, категория, характеристики, описание, ключевые слова, SEO, варианты, цвета, размеры, материал, комплектация, совместимые товары, необходимые документы
3. **Проверьте** draft — неподтверждённые данные помечаются
4. Нажмите **Опубликовать** — требуется подтверждение

Запрещены автоматически выдуманные характеристики.

## Таблица товаров (spec §9)

Колонки: фото, SKU, название, категория, цена, количество, наличие, подтверждение продавца, срок продажи, авто-продление, статус, просмотры, заказы, конверсия, рейтинг.

Действия: edit, hide, publish, подтвердить наличие, продлить, изменить количество, изменить цену, дублировать, архивировать.

## Наличие товара (spec §10, §24)

Товар находится **у вас** — своих складов у платформы пока нет.

Каждый товар имеет: `CONFIRMED_BY_SELLER`, `CONFIRMED_AT`, `QUANTITY`, `SALE_UNTIL`, `AUTO_EXTEND`.

- **[Подтвердить наличие]** — обновить `CONFIRMED_AT`
- **[Продлить срок продажи]** — отодвинуть `SALE_UNTIL`
- **[Автоматически продлевать]** — авто-продление при подтверждении

Если подтверждение просрочено:
1. Платформа предупреждает вас
2. Товар **не предлагается** как гарантированно доступный
3. При необходимости товар скрывается
4. Вся история сохраняется

## Аналитика (spec §50)

Спросите Светлану: «Почему упали продажи?»

Система анализирует: продажи, трафик, конверсию, цену, остатки, отзывы, конкурентов, доставку — и формирует список возможных причин на основании данных.

Также: «Что мне добавить в ассортимент?», «Какие товары заканчиваются?», «Что продлить?»

## Конкуренты (spec §13)

- «Найди конкурентов этого товара» — по карточке
- «Я сфотографировал товар конкурента» — по фотографии

Сравнивает: товар, цену, фото, характеристики, отзывы, рейтинг, наличие, доставку. Использует **только публично доступные** данные. Закрытые данные не собираются.

## Ценообразование (spec §19, §54)

Светлана анализирует цену конкурентов, спрос, остаток, историю цены, сезонность, комиссии.

«При текущей цене товар выше большинства сопоставимых предложений.»

**Изменение цены — только после вашего подтверждения** (HIGH_RISK_WRITE).

## Продажа без AI (spec §112)

Продавец может работать полностью вручную — AI ускоритель, а не обязательная зависимость. Все действия доступны без AI.

## Автоматизация (spec §113, §114)

Workflow builder из естественного языка:

> «Светлана, если цена конкурентов становится ниже нашей, сообщай мне.»

AI переводит запрос в структурированное правило (`WorkflowRule`).

Готовые шаблоны: inventory low → notify; availability expires → ask to renew; new review → prepare response draft.
